# 用户操作手册

## 1. 登录

输入管理员分配的账号和密码后选择登录。无法登录时，请确认账号未被停用并联系管理员；不要在搜索备注或截图中记录密码。

## 2. 手动查询

1. 在查询框输入车牌片段。
2. 输入首个有效车牌字符后，系统自动显示候选。
3. 英文字母不区分大小写，空格和常见分隔符不会影响匹配。
4. 候选仅显示车牌和车辆所属类型。
5. 选择候选进入详情页，按现场需要核对人员、身份证号、单位、通行人员和业务字段。

候选按精确匹配、前缀匹配、包含匹配排序，最多显示 20 条。

## 3. 历史记录

历史记录仅保存在当前登录账号的本机设备中，按最近时间排序。记录只含车牌、车辆类型、车辆标识和时间，不保存身份证号、联系方式或车辆详情。可删除单条记录或清空当前账号记录。

## 4. 异常提示

- 未找到匹配：核对车牌片段，必要时输入更多字符。
- 无法连接服务：确认网络后选择重试；系统不会展示过期车辆详情。
- 登录状态失效：重新登录。
- 无管理员权限：普通用户不能进入管理工作台。
