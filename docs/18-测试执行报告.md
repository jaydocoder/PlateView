## 2. 调试交付范围

本轮交付为调试 APK，Android 自动调试签名已满足本机和真机安装要求。未签名发布 APK 不属于本轮调试验收范围；在需要对外分发、上架或需要版本覆盖安装时，必须配置发布密钥后构建正式签名 APK。

## 3. ColorOS 真机安装说明

本轮 Android 12 真机已解锁。ColorOS 会把由 ADB 安装的仪器化测试 APK 显示为“电脑端未知来源”，并要求依次确认“继续安装”和“完成”。Gradle 无法等待该交互，可能在安装尚未完成时启动运行器，并产生“找不到 instrumentation target package”的假失败。

完成系统安装确认后，先确认目标包和测试包均存在，再直接调用测试运行器。这不是签名错误，也不需要发布签名：两个 APK 均使用同一份 Android 调试证书。

## 4. 本地复现命令

```bash
cd /home/neo/project/AiProject/codex-ui/PlateView/server
./gradlew --no-daemon --max-workers=1 --rerun-tasks test

cd /home/neo/project/AiProject/codex-ui/PlateView/android
./gradlew --no-daemon --offline --max-workers=1 \
  -Dorg.gradle.jvmargs='-Xmx1024m -XX:MaxMetaspaceSize=384m' \
  -Dkotlin.compiler.execution.strategy=in-process \
  -Dkotlin.incremental=false \
  :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest

# 在已解锁、允许安装测试 APK 的 Android 12 及以上设备执行：
./gradlew --no-daemon --max-workers=1 \
  -Dorg.gradle.jvmargs='-Xmx1024m -XX:MaxMetaspaceSize=384m' \
  -Dkotlin.compiler.execution.strategy=in-process \
  -Dkotlin.incremental=false \
  :app:connectedDebugAndroidTest

# ColorOS 出现未知来源安装确认并导致上述命令提前失败时：
adb install -r -t app/build/outputs/apk/debug/app-debug.apk
adb install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell pm path com.jaydocoder.plateview
adb shell pm path com.jaydocoder.plateview.test
adb shell am instrument -w -r \
  com.jaydocoder.plateview.test/androidx.test.runner.AndroidJUnitRunner
```
