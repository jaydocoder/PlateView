# 权限与个人信息规范

## 1. 授权矩阵

| 资源 | 普通用户 | 管理员 |
| --- | --- | --- |
| 登录与退出 | 允许 | 允许 |
| 模糊搜索与车辆详情 | 允许 | 允许 |
| 本机搜索历史 | 仅本人 | 仅本人 |
| 车辆档案 | 只读 | 创建、编辑、停用、查看历史版本 |
| Excel 导入 | 不允许 | 预览、处理异常、发布、回滚 |
| 用户与角色 | 不允许 | 创建、停用、启用、分配角色 |
| 审计记录 | 不允许 | 只读查询 |

## 2. 身份信息处理

- 已登录普通用户和管理员均可在车辆详情查看完整身份证号，符合已确认业务需求。
- 身份证号、联系方式、密码和令牌不得写入客户端日志、服务端应用日志、崩溃上报、搜索历史、测试夹具或错误消息。
- 候选列表仅展示车牌和车辆所属类型，不展示姓名、单位、身份证号或联系方式。
- 测试、演示和文档必须使用脱敏或虚构数据。

## 3. 会话与账号

- 使用账号密码登录；后端保存不可逆的密码哈希，不保存明文密码。
- 初始管理员用户名为 `admin`，部署时从未提交的环境变量设置初始密码。
- 管理员可创建账号、启用或停用账号、调整角色；角色或状态变更后该用户下次请求立即按新状态校验。当前登录管理员不能停用或降级自身，且系统至少保留一个启用的管理员账号。
- App 退出登录后清除访问令牌和当前账号的内存状态。

## 4. 审计

| 事件 | 必填记录 |
| --- | --- |
| 车辆详情查询 | 账号、时间、规范化车牌、结果状态、设备摘要。 |
| 车辆创建/编辑/停用 | 操作人、时间、对象、结果状态；车辆使用逻辑停用保留导入与审计可追溯性。 |
| 用户管理 | 操作人、目标账号、动作、时间。 |
| 导入预览/发布/回滚 | 操作人、批次、来源文件标识、统计结果、时间。 |

审计记录只追加，不提供业务接口修改或删除。
