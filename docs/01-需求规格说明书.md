# PlateView 需求规格说明书

## 1. 产品目标

PlateView 用于景区入口、巡查和核验场景。已登录用户通过手动或语音输入车牌片段，快速确认车辆类别、所属人员或单位及通行相关信息。管理员在同一系统内维护账号、车辆档案和 Excel 导入数据。

## 2. 范围

### 2.1 首版范围

- Android 12 及以上的原生 Android App。
- 账号密码登录、普通用户与管理员两类角色。
- 手动输入与系统语音输入车牌。
- 车牌模糊候选、车辆详情和本机搜索历史。
- 村民车辆和四类长期车辆查询。
- 管理员的账号管理、车辆增删改查、Excel 导入预览与发布。
- Kotlin/Ktor/PostgreSQL 后端及 Docker Compose 部署包。

### 2.2 非首版范围

- 自助注册、短信登录、跨设备同步搜索历史。
- 车辆详情离线缓存、车牌图像识别、自动放行控制。
- 生产服务器、域名和应用商店发布。

## 3. 角色与权限

| 角色 | 能力 |
| --- | --- |
| 普通用户 | 登录、语音或手动搜索、查看候选和详情、管理本人本机搜索历史。 |
| 管理员 | 继承普通用户能力，管理用户与角色、车辆档案、Excel 导入批次和操作审计。 |

## 4. 核心业务流程

1. 用户登录后进入查询页。
2. 用户手动输入或点击语音按钮说出车牌片段。
3. App 对输入归一化并统一字母大小写；输入首个有效车牌字符后进行防抖查询。
4. 系统展示最多 20 条候选，按精确、前缀、包含匹配排序。
5. 用户点击候选车牌进入详情，核验车辆类别、人员或单位、通行信息和其余字段。
6. 系统记录一次详情查询审计；本机仅保存不含身份信息的搜索历史。

## 5. 车辆分类与展示

- 村民车辆：显示车牌、类别、姓名、身份证号、联系方式、备注及其余字段。
- 驻景区单位车辆：显示车牌、单位、通行人员、用途、区域、车型和备注。
- 驻景区企业车辆：显示车牌、企业、通行人员、用途、区域、车型和备注。
- 干部车辆：显示车牌、单位、通行人员、职务、用途、区域和备注。
- 喀纳斯旅游发展股份有限公司车辆：显示车牌、品牌型号、核载人数、号牌颜色和备注。

## 6. 关键业务规则

- 车牌查询不区分空格、中点、连字符和大小写。
- 搜索候选不展示身份证号与联系方式；完整详情仅对已登录用户开放。
- 无结果、网络不可用、语音识别失败和无麦克风权限必须有明确提示和手动输入入口。
- 车辆数据不离线缓存；网络不可用时不展示可能过期的车辆详情。
- 管理员导入必须经过预览和确认发布；异常数据不得自动进入正式库。

## 7. 验收标准

- Android 12、13、14 设备或模拟器可安装、登录、查询并查看详情。
- 模糊查询输入归一化后首个有效车牌字符即触发，忽略字母大小写，最多返回 20 条仅含车牌和车辆所属类型的候选。
- 正常网络下 95% 已认证查询响应小于 1 秒。
- 普通用户无法访问管理员页面或管理员 API。
- 每次数据修改、导入发布和详情查询均可追溯。
