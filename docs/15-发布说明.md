# 发布说明

## 版本

- 应用：PlateView
- 版本：`0.3.5`
- 最低 Android 版本：Android 12（API 31）

## 本版本能力

- 账号登录与普通用户、管理员角色分离。
- 首字符触发、大小写不敏感的车牌模糊查询。
- 村民与长期车辆详情核验。
- 手动输入与实时车牌模糊查询。
- 当前账号隔离的本机搜索历史。
- 管理员车辆、账号、导入、发布、回滚和审计工作台。
- Ktor、PostgreSQL、Flyway 与 Docker Compose 部署路径。

## 已验证内容

服务端自动化、Android JVM、Lint、调试构建、数据库迁移、两份真实工作簿导入与回滚、查询详情、权限、管理员管理、审计、查询性能和 Android 12 真机验收均已通过。

## 发布阻断项

本版本已满足调试交付。当前 `app-release-unsigned.apk` 未签名，不能作为正式 APK；对外分发、应用市场上架或需要后续版本覆盖安装时，必须提供发布密钥与签名配置后重新构建。

## 发布与回滚

- 发布前：执行部署手册、完整测试、备份与正式签名验证。
- 发布后：抽样验证登录、搜索、详情、管理员和审计。
- 数据问题：优先使用导入批次回滚；系统冲突时停止回滚并人工核对。
- 版本问题：保留上一版已签名 APK 与数据库备份，完成隔离恢复演练后再执行生产回退。
