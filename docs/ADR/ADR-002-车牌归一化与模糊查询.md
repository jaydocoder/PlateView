# ADR-002：使用归一化车牌和 PostgreSQL 三元组索引进行模糊查询

- **状态：** 已接受
- **日期：** 2026-08-06

## 背景

源数据包含空格、中点、连字符和大小写差异；现场用户需要通过数字、字母或部分车牌快速找到候选车辆。

## 决策

保存原始车牌和 `normalizedPlate`。归一化时统一转大写并删除无语义分隔符。搜索输入首个有效车牌字符后即触发，按精确匹配、前缀匹配、包含匹配排序，最多返回 20 条仅含车牌和车辆所属类型的候选。PostgreSQL 为归一化车牌建立 `pg_trgm` GIN 索引。

## 后果

- 用户不需要准确输入原始格式即可检索。
- 结果可解释且适合小屏候选列表。
- 导入时必须先生成规范化车牌；无法归一化的数据进入异常队列。
- 不对姓名、身份证号和联系方式执行模糊检索。
