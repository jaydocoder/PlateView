# ADR-008：移除系统语音输入

## 状态

已采纳，2026-08-10。

## 背景

部分目标 Android 设备无法稳定提供可用的系统语音识别服务。应用不能通过公开 Android API 自动调用用户输入法的语音按钮，外部云语音服务又会引入额度、网络和运维依赖。

## 决策

- 删除 Android 系统语音识别、录音权限、系统识别 Intent 查询和相关界面状态。
- 普通用户仅通过手动输入车牌片段完成实时模糊查询。
- 保留输入归一化、防抖、本地目录快照、候选排序、详情核验与搜索历史。

## 后果

- 查询链路不再依赖设备语音服务或外部语音接口。
- 用户使用输入法自行输入的文本仍会触发现有模糊查询。
- `ADR-007` 中关于系统语音兜底的决策被本 ADR 替代；其中审计分页决策继续有效。
