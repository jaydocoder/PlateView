# ADR-007：系统语音兜底与审计分页

## 状态

已采纳，2026-08-09。

## 背景

部分 Android 12 设备安装了语音识别服务，但未设置默认直接识别服务，导致 `SpeechRecognizer` 无法完成绑定。管理员审计页此前固定读取 100 条记录，无法在长周期内按异常和操作人排查问题。

## 决策

- 保留 `SpeechRecognizer` 作为快速路径；直接服务不可用或出现客户端服务错误时，使用 `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` 调起系统配置的识别界面。
- 不接入第三方云语音服务，不上传录音，不新增密钥或服务端成本。
- 审计接口采用服务端计算时间范围的参数化筛选和偏移分页，默认最近 30 天、每页 50 条。
- `FAILURE` 与 `DENIED` 聚合为异常；同一筛选条件同时返回列表、总数、汇总、可选操作人和操作类型。
- 通过 Flyway 为时间倒序和按结果加时间筛选建立索引。

## 后果

- 用户可在未配置直接识别服务时继续使用系统语音界面，取消或无结果不会阻断手动输入。
- 审计查询增加汇总与选项查询开销，但换取可操作的运维视图；索引降低常用时间范围和异常筛选的扫描成本。
- 发布顺序必须先部署服务端迁移与新响应，再发布 Android APK。
