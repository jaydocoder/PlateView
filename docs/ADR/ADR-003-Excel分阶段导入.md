# ADR-003：Excel 导入采用预览、确认发布和回滚的分阶段流程

- **状态：** 已接受
- **日期：** 2026-08-06

## 背景

两份 Excel 存在跨行单位、多车牌单元格、重复车牌和字段结构差异。直接导入可能污染正式查询结果。

## 决策

上传 Excel 后先创建导入批次和行级解析记录。系统输出新增、更新、重复、异常统计；管理员处理异常并确认后才在事务中发布。每条记录保留来源文件、工作表、源行、原始值与解析值；已发布批次支持业务层回滚。

## 后果

- 正式数据不会因一次错误上传被部分覆盖。
- 数据管理员能追溯和处置异常。
- 导入服务需要批次、行记录、状态机和回滚测试。
