# ADR-001：采用 Kotlin、Ktor 与 PostgreSQL 构建自建后端

- **状态：** 已接受
- **日期：** 2026-08-06

## 背景

PlateView 需要多设备共享车辆数据、账号登录、角色授权、导入批次、审计记录和管理员维护能力。本地数据库无法作为跨设备权限与数据的一致来源。

## 决策

后端使用 Kotlin、Ktor、PostgreSQL 和 Docker Compose。对 Android 客户端提供版本化 REST API。

## 后果

- Android 与后端共享 Kotlin 语言生态，降低领域模型和维护成本。
- PostgreSQL 提供事务、索引、JSON 保留字段和可靠的数据迁移能力。
- Docker Compose 支持本地一致运行与后续服务器部署。
- 必须维护数据库迁移、环境变量、备份和恢复流程。
