# ADR-009：导入差异核对与全量失效同步

## 状态

已采纳。

## 背景

原导入预览以 Excel 行为中心，管理员无法快速识别正式库字段变化，也不会处理同一已识别类别中已从新表消失的旧车辆。该行为不符合以最新核对表作为类别内有效目录的业务要求。

## 决策

1. 按本次 Excel 中成功识别的车辆类别进行全量差异比较，不影响未出现的类别。
2. 默认只展示新增、更新、恢复有效、待失效和解析异常；完全一致记录保留审计但隐藏。
3. `import_rows.before_values` 保存创建预览时的正式库快照，详情接口仅返回字段级差异与 Excel 源字段。
4. 新表缺失的有效车辆生成系统来源的 `DEACTIVATE` 记录，管理员确认后逻辑停用；已失效车辆重现生成 `REACTIVATE` 记录。
5. 发布前服务端在同一事务校验所有待确认项均已处置，并对更新、失效、恢复执行车辆版本校验。
6. 回滚复用导入效果快照，覆盖创建、更新、失效和恢复动作。

## 后果

- 管理员获得可审计的字段对比和逐条失效确认流程。
- 预览创建时需要扫描已识别类别的有效车辆，导入规模受现有 10000 行上限约束。
- 部署必须先执行 `V14__add_import_diff_review.sql`，再发布 Android 客户端。
