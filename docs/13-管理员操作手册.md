# 管理员操作手册

## 1. 工作台范围

管理员登录后可使用概览、车辆、账号、导入和审计五个标签页。普通用户没有管理入口，服务端也会拒绝其管理员请求。

## 2. 车辆管理

1. 在“车辆”页选择新增或编辑。
2. 选择车辆所属类型。
3. 村民车辆填写姓名、身份证号及其余可用字段。
4. 长期车辆填写单位、通行人员、通行说明及对应字段。
5. 保存前复核车牌、类别和核验资料。
6. 停用使用“逻辑停用”，不物理删除车辆、导入效果或审计记录。

保存时若提示冲突，先刷新记录，再基于最新版本重新编辑。管理员不得停用或降级当前会话账号，系统始终保留至少一个启用管理员。

## 3. 账号管理

1. 新建账号时填写账号、密码和角色。
2. 普通用户只可登录、查询和查看详情。
3. 管理员可维护车辆、账号、导入与审计。
4. 账号状态使用“启用”或“停用”；停用值为 `DISABLED`，停用后不能登录。

不得在账号名称、备注、审计说明或截图中记录真实密码。

## 4. Excel 导入

1. 在“导入”页通过系统文件选择器选择 `.xlsx` 或 `.xls` 文件。
2. 等待预览完成，检查新增、更新、重复、异常和待确认数量。
3. 对待确认行明确选择发布或跳过；异常行不能发布。
4. 确认全部待处置行后执行发布。
5. 发布后用普通用户查询抽样核验车牌、类型和详情。

系统支持村民车辆、驻景区单位、驻景区企业、干部车辆和喀纳斯旅游发展股份有限公司车辆。工作簿中的身份证号、联系方式和人员信息不得复制到外部日志。

## 5. 回滚

在已发布批次详情中选择回滚。系统会验证车辆自发布后未被后续编辑或其他批次更新；若发生版本冲突，必须重新核对数据，不得绕过冲突直接覆盖。

## 6. 审计

审计页默认显示最近 30 天记录，并可按近 24 小时、近 7 天、近 30 天或全部时间切换。可组合筛选操作人、操作类型、结果和关键词；关键词匹配账号、操作、目标类型或目标标识。列表每次加载 50 条，继续下滑才请求下一页。

顶部指标显示当前筛选范围内的总记录、正常数、异常数和活跃操作人。`FAILURE` 与 `DENIED` 统一显示为红色异常状态；审计不显示密码、令牌、身份证号或联系方式。出现核验争议时，以审计记录、导入批次和源工作簿为依据追溯。
