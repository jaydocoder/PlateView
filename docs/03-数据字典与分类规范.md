# 数据字典与分类规范

## 1. 车辆主档案

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT | 主键。 |
| plate_number | 文本 | 来源中的原始车牌。 |
| normalized_plate | 文本 | 用于唯一校验和模糊查询的归一化车牌。 |
| category | 枚举 | `RESIDENT`、`SCENIC_UNIT`、`SCENIC_ENTERPRISE`、`CADRE`、`KANAS_TOURISM_DEVELOPMENT`。 |
| vehicle_type | 文本 | 车型或车辆类型。 |
| status | 枚举 | `ACTIVE`、`INACTIVE`。 |
| version | 整数 | 乐观锁版本号。 |
| extra_fields | JSON | 保留源表中未标准化字段。 |

## 2. 分类档案

| 分类 | 专属字段 |
| --- | --- |
| 村民车辆 | 姓名、身份证号、联系方式、备注。 |
| 驻景区单位/企业 | 单位名称、通行人员、车辆用途、通行区域、备注。 |
| 干部车辆 | 单位名称、通行人员、职务、车辆用途、通行区域、备注。 |
| 旅游发展股份有限公司车辆 | 品牌型号、核载人数、号牌颜色、备注。 |

## 3. 车牌归一化

1. 去除首尾空白并转换为大写。
2. 删除空格、全角空格、中点、中文点号、连字符和无意义分隔符。
3. 保留省份简称、汉字、字母、数字和必要的新能源标识字符。
4. 原始值无法产生有效检索键时，记录为导入异常；查询时同样忽略大小写和无语义分隔符。
5. 查询输入归一化后少于 4 个有效车牌字符时，不执行模糊检索。

## 4. 搜索历史

搜索历史仅保存：本机账号标识、已选车牌、车辆类别和查询时间。不得保存身份证号、联系方式、详情字段或语音原文。
