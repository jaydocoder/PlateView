# 系统架构设计

## 1. 总体结构

```text
Android App
  ├─ Compose 界面与 Navigation
  ├─ ViewModel 与用例层
  ├─ 网络仓库与本机搜索历史 Room
          │ HTTPS
Ktor API
  ├─ 认证与角色授权
  ├─ 车辆查询与管理
  ├─ Excel 导入服务
  └─ 审计服务
          │
PostgreSQL
```

## 2. Android 分层

- 展示层：Composable、ViewModel、界面状态、事件和导航。
- 领域层：登录、搜索、查询详情、管理车辆、导入预览等用例。
- 数据层：Ktor API 客户端、Room 搜索历史、仓库实现和 DTO 映射。
- 依赖由 Hilt 提供；ViewModel 以 StateFlow 输出状态。

## 3. 后端模块

- `auth`：账号、密码哈希、登录、令牌和角色校验。
- `vehicle`：车辆主档案、分类档案、模糊查询和乐观锁编辑。
- `import`：文件解析、预览、异常、发布、回滚。
- `audit`：追加式查询和管理操作记录。
- `admin`：用户、角色、车辆和导入批次管理。

## 4. 非功能设计

- PostgreSQL 对 `normalized_plate` 建立 `pg_trgm` GIN 索引。
- 后端提供 `/health` 健康检查；Docker Compose 分离 API、数据库和持久卷。
- 所有写操作使用事务；编辑接口携带版本号实现乐观锁。
- 正式数据只由后端提供，Room 不保存车辆详情。
