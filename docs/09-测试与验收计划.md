# 测试与验收计划

## 1. 测试层级

| 层级 | 覆盖内容 |
| --- | --- |
| 单元测试 | 车牌归一化、排序、权限、导入解析、版本冲突、历史记录。 |
| 后端集成测试 | Ktor 接口、PostgreSQL、认证、角色授权、事务、审计。 |
| 导入测试 | 两份 Excel 的正常行、跨行单位、多车牌、重复和异常记录。 |
| Android UI 测试 | 登录、手动查询、语音回填、候选跳转、详情、历史和权限入口。 |
| 仪器化测试 | 录音权限、网络错误、Android 12/13/14 兼容性。 |
| 验收测试 | 管理员 CRUD、导入预览发布回滚、备份恢复和 APK 安装。 |

## 2. 关键场景

- 输入数字、字母和混合片段均可得到正确候选排序。
- 输入不足两个有效字符不发起查询。
- 语音结果可编辑；权限拒绝和识别失败不阻断手动查询。
- 普通用户请求任一管理员 API 必须被拒绝。
- 管理员并发编辑同一车辆时，旧版本保存返回冲突。
- 导入异常行不可发布；发布失败不产生部分写入。
- 断网时展示无法连接服务，不展示旧车辆详情。

## 3. 通过条件

- 全部自动化测试通过，且无高优先级缺陷。
- 正常网络下 95% 查询请求小于 1 秒。
- Android 12、13、14 的目标设备或模拟器均完成核心流程验证。
- 调试 APK 和正式签名 APK 可安装并显示正确版本信息。
