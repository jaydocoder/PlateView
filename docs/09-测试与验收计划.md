# 测试与验收计划

## 1. 测试层级

| 层级 | 覆盖内容 |
| --- | --- |
| 单元测试 | 车牌归一化、排序、权限、导入解析、版本冲突、历史记录。 |
| 后端集成测试 | Ktor 接口、PostgreSQL、认证、角色授权、事务、审计。 |
| 导入测试 | 两份 Excel 的正常行、跨行单位、多车牌、重复和异常记录。 |
| Android UI 测试 | 登录、手动查询、语音回填、候选跳转、详情、历史和权限入口。 |
| 仪器化测试 | 录音权限、网络错误、Android 12/13/14 兼容性。 |
| 验收测试 | 管理员 CRUD、导入预览发布回滚、备份恢复和 APK 安装。 |

## 2. 关键场景

- 输入数字、字母和混合片段均可得到正确候选排序。
- 输入归一化后不足四个有效车牌字符不发起查询，字母大小写不得影响匹配结果。
- 语音结果可编辑；权限拒绝和识别失败不阻断手动查询。
- 直接语音识别服务不可用时，必须调起系统语音识别界面；取消、无结果和无可处理界面均给出明确提示。
- 审计默认最近 30 天，时间、操作人、操作、结果和关键词组合筛选必须返回正确汇总与总数；异常记录以红色状态和图标呈现。
- 审计列表每页 50 条，接近底部加载下一页；筛选条件改变必须清空旧页并从偏移量 0 重新加载。
- 普通用户请求任一管理员 API 必须被拒绝。
- 管理员并发编辑同一车辆时，旧版本保存返回冲突。
- 导入异常行不可发布；发布失败不产生部分写入。
- 断网时展示最近一次完整加密快照的详情；首次没有快照时展示无法连接服务。

## 3. 通过条件

- 全部自动化测试通过，且无高优先级缺陷。
- 正常网络下 95% 查询请求小于 1 秒。
- Android 12、13、14 的目标设备或模拟器均完成核心流程验证。
- 调试 APK 和正式签名 APK 可安装并显示正确版本信息。

## 3.1 加密缓存验收

- SQLCipher Room 数据库可在 Android 12 真机创建并读写，数据库密码不得明文出现在偏好设置。
- 完整目录在设备内共享，本地模糊查询在约 1200 条目录下 P95 小于 100 毫秒。
- 目录版本变化时，完整快照必须在所有分页成功后原子切换；同步失败不得删除旧快照。
- 全部车辆详情可离线读取；首次快照不存在时必须展示网络不可用状态。
- 退出登录后快照保留，但未登录状态不得访问。
- WorkManager 周期同步、应用前台恢复与首次查询均会触发版本核验。
