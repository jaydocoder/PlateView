# Excel 导入与数据质量规范

## 1. 数据源

| 来源 | 工作表或字段特点 | 目标分类 |
| --- | --- | --- |
| 村民车辆统计表 | 姓名、身份证号、车牌号、联系方式、备注 | 村民车辆 |
| 长期通行工作用车统计表：驻景区单位 | 单位跨行继承 | 驻景区单位 |
| 长期通行工作用车统计表：驻景区企业 | 通行人员字段可能包含混合文本 | 驻景区企业 |
| 长期通行工作用车统计表：干部车辆 | 包含职务字段 | 干部车辆 |
| 长期通行工作用车统计表：旅游发展车辆 | 品牌、核载人数、号牌颜色 | 喀纳斯旅游发展股份有限公司车辆 |

## 2. 导入流程

1. 管理员上传 Excel，系统创建导入批次，不修改正式数据。
2. 解析器按工作表映射字段，继承空白单位名称，生成归一化车牌；支持普通车牌、警车后缀和应急车后缀，并完整保留后缀作为检索键。
3. 系统分类展示新增、更新、重复和异常记录。
4. 管理员修正异常或放弃异常行，确认后发布批次。预览首屏按页返回，继续下滑才加载后续记录。
5. 发布在事务中执行，失败则整体回滚；成功后记录审计和版本信息。

## 3. 异常规则

| 情况 | 处理 |
| --- | --- |
| 车牌为空或无法归一化 | 异常，禁止发布该行。 |
| 警车或应急车后缀 | 识别为完整车牌，后缀参与唯一校验和模糊查询，不截断为普通车牌前缀。 |
| 单元格存在多个可识别车牌 | 拆分后进入待确认记录；无法确定关联字段时标记异常。 |
| 规范化车牌与正式库冲突 | 显示来源与字段差异，管理员选择更新、保留或放弃。 |
| 身份证号或联系方式格式异常 | 标记警告，管理员确认后可发布。 |
| 单位名称为空 | 仅可继承上一有效单位；首条无单位记录为异常。 |
| 姓名、身份证号、联系方式、车辆类型、单位名称或通行人员超过数据库字段上限 | 异常，定位到源行后修正，不阻断同批次其他合格记录。 |

## 4. 可追溯性与回滚

每条导入记录保存批次号、源文件标识、工作表名、源行号、原始值、解析值和处理状态。管理员可回滚已发布批次，回滚行为同样进入审计记录。

发布时系统为每条实际创建或更新的车辆写入效果快照。回滚前必须确认车辆版本仍与发布结果一致；存在后续编辑或其他批次更新时，系统拒绝整个回滚操作，避免覆盖后续数据。
